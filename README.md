# 文艺逼表达转换器

**把随口一句，写得郑重其事。**

![文艺逼表达转换器：普通话失踪事件](assets/poster.png)

一个把普通中文改写成文艺腔的 Codex skill。你给它一句“我想你了”“我饿了”或“今天不想上班”，它会从作家的作品、具体意象和叙述方式里找到联想，让小事多出一层值得认真讲述的意味。语气有些深沉，有些自我欣赏，也藏着一点不动声色的好笑。

## 看一句就懂

原句：**等你回消息。**

> 等你回消息这件事，被我摆出了沈从文《边城》里渡口的架势；手机这么小，心事倒很会临水而居。

这是原创联想。作者和作品通过等待的姿态进入句子，末尾落回手机与心事的小反差，读起来仍像一个人在说话。

## 能做什么

- **把小事写出排场**：给吃饭、睡觉、回消息等日常动作安排一个郑重的精神解释。
- **让作者自然入场**：用作品中的场景、物件、动作与时间感推进同一件事，让名字有具体来处。
- **保留原意与用途**：维持原话的人物关系、事实、情绪、时间和条件；请求、拒绝、道歉也保持清楚。
- **校对自然表达**：已内置 humanizer-zh 的适用原则，调整空话、重复和别扭的衔接，保留用户需要的文艺姿态，无需另装依赖。

适合聊天回复、朋友圈、节日祝福、日常吐槽和私人情绪表达。

## 五种口味

| 口味 | 表达感觉 |
| --- | --- |
| 冷面自嘲 | 一本正经地看待自己，露出一点文学排场里的小失算。 |
| 荒诞认真 | 给普通小事安排近乎典礼的规格。 |
| 日常审美 | 细看眼前的滋味、声音和小舒服。 |
| 含蓄思念 | 把情绪放进停顿、距离和物件里。 |
| 热烈掉书袋 | 让多位作者为欢喜、想念或祝福壮胆。 |

**默认中档强度、3 位作者、2–4 句。** 强度、作者数量与长度分别控制：轻一点也可以带三位作者，重一点也可以只带一位。“自然一点”主要调整措辞与节奏；“收一点”则降低文艺强度。

## 作者库

目前收录 **27 位作者，其中国内作者 13 位**。国内包括沈从文、老舍、迟子建、李娟、史铁生、余华、木心、海子、张爱玲、汪曾祺、王小波、鲁迅、苏轼；外国包括普鲁斯特、杜拉斯、伍尔夫、博尔赫斯、卡夫卡等。

参考资料按主题整理作品来源、理解、适用情绪与搭配方式。改写默认采用原创联想，指定真实引文时另行核对出处。

## 使用方法

安装后，直接调用 `$wenyi-bi` 并提供原句，也可以附上偏好：

```text
$wenyi-bi 我想你了

$wenyi-bi 把“我国庆一个人在寝室，好孤独”改成冷面自嘲，
带三位国内作者，短一点。

$wenyi-bi 把“我喜欢睡懒觉”写得更装一点，只带一位作者。
```

## 安装到 Codex

下载本仓库并解压，将包含 `SKILL.md`、`agents`、`references` 和 `assets` 的完整目录命名为 `wenyi-bi`，放入个人技能目录：

- Windows：`%USERPROFILE%\.codex\skills\wenyi-bi`
- macOS / Linux：`~/.codex/skills/wenyi-bi`

完成安装后，在聊天中输入 `$wenyi-bi` 调用。完整规则见 [SKILL.md](SKILL.md)。
